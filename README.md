# Supermarket REST API Game

משחק אינטראקטיבי ללימוד ותרגול תקשורת HTTP ועקרונות REST API, שנבנה במסגרת מטלה 3.
הפרויקט מדמה שרת של סופרמרקט (ניהול מוצרים וקטגוריות) ומאפשר למשתמש להרכיב ולשלוח בקשות HTTP אמיתיות לשרת Node.js/Express, לקבל תשובות בזמן אמת ולהבין את הסטטוסים והנתונים המוחזרים.

---

## דרישות מוקדמות

לפני הפעלת הפרויקט יש לוודא שמותקנת במחשב סביבת הרצה של Node.js.
לבדיקת הגרסה המותקנת, יש להריץ בטרמינל:
```bash
node -v
```
אם התוכנה אינה מותקנת, ניתן להוריד אותה מהאתר הרשמי של Node.js.

---

## הוראות התקנה והרצה

1. פתחו את הטרמינל (Terminal / Command Prompt) בתיקיית הפרויקט.
2. הריצו את הפקודה להתקנת התלויות (Express, EJS):
   ```
   npm install express ejs
   ```
3. הריצו את הפקודה להפעלת השרת:
   ```
   npm start
   ```
4. כדי לגשת למשחק, פתחו את הדפדפן והיכנסו לכתובת:
   `http://localhost:3000`

---

## אופן המשחק

המשחק מורכב מ-8 שלבים שונים. בכל שלב מוצגת משימה אותה יש לבצע מול השרת.

על המשתמש להרכיב את הבקשה בטופס הקיים בעמוד:
* **HTTP Method:** בחירת השיטה המתאימה (GET, POST, PATCH, DELETE).
* **Route:** הזנת הנתיב המבוקש (למשל `/api/products` או `/api/categories/2`).
* **Query Parameters:** במידת הצורך, הוספת פרמטרים בנתיב (למשל `/api/products?minPrice=10&maxPrice=20`).
* **Request Body:** עבור בקשות יצירה או עדכון, הזנת הנתונים בפורמט JSON תקין.

לחיצה על כפתור השליחה שולחת בקשת AJAX לשרת. השרת בודק את נכונות הבקשה ומחזיר את תשובת ה-JSON, קוד סטטוס HTTP (כגון 200, 201, 404), ומחזיר האם המשימה בוצעה בהצלחה.

ניתן לצפות בסכמות ובמבנה השדות של המערכת בכתובת: `http://localhost:3000/schemas`.
